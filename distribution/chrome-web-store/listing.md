## Short description
Connect this browser to Synchrome for macOS to sync bookmarks and your installed extensions across your Macs.

## Detailed description
Synchrome connects this browser profile to a shared profile in the Synchrome app for macOS.
Keep your bookmarks and installed extension list in sync across your Macs, and review connection status from the companion popup.

What the companion does:
• Sends bookmark titles, URLs, folders and changes to the Synchrome app, and applies synchronized bookmark changes received from it.
• Shares installed extension names, identifiers, versions and enabled state with the app. Applies supported enable/disable changes and provides user actions when confirmation is needed.
• Shows connection status, pending changes and conflicts. Resolve conflicts in the Synchrome app.

Before you install:
• Install Synchrome for macOS, sign in and connect your browser profile in the app.
• Install the browser connector using Synchrome's setup assistant.
• This extension works with the separate desktop app; it is not a standalone synchronization service.
• Each shared Synchrome profile supports one browser connection per Mac in this version.

Privacy:
The companion communicates with the Synchrome app through Chrome's native messaging interface. It does not connect directly to a cloud service. The desktop app synchronizes selected data with your Synchrome account.
The companion does not read your browsing history, page content, passwords, cookies or login sessions. No advertising or analytics code is included.

Supported extension settings and browser preferences are separate opt-in desktop-app features. The companion does not promise synchronization of arbitrary extension files or browser data.
